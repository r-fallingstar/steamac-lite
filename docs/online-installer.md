# BOOTH版の導入方法

1. ZIPを展開し、`Install SteamAC Lite.app`を開きます。
2. 表示言語とインストール先を確認し、「インストール」を押します。
3. 最新版の取得と検証が終わったら「SteamAC Liteを開く」を押します。
4. 本体で表示言語を選び、[導入ガイド](https://r-fallingstar.github.io/steamac-lite/?lang=ja)に沿ってSteamOSの準備を進めます。

すでに最新版が入っている場合は再インストールしません。既存のSteamOSディスクと設定は引き継ぎます。起動中の本体を更新する場合は、先にSteamAC Liteを終了してください。

通信に失敗した場合は「手動ダウンロード」から[GitHub Release](https://github.com/r-fallingstar/steamac-lite/releases)のDMGを取得できます。本体の導入後はアプリ内の更新機能を使えます。

インストーラーはApple未公証です。macOSで確認が表示された場合は、入手元を確かめ、導入ガイドに沿ってご自身で許可してください。
