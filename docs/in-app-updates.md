# アプリ内更新（Lite.9以降）

操作手順は[更新サポートページ](https://r-fallingstar.github.io/steamac-lite/support/?lang=ja)をご覧ください。

起動時と起動中の6時間ごとに、このForkのGitHub Releaseを確認します。新しい版があれば更新画面を表示します。「アップデート」でダウンロードし、「更新して開き直す」で反映します。SteamOSを実行中なら正常に終了するまで待ちます。更新するのはアプリだけです。SteamOSのディスク、インストールしたゲーム、設定は引き継ぎます。

「あとで通知」「このバージョンをスキップ」も選べます。自動確認は「設定 → 一般」でオフにできます。アプリの「アップデートを確認…」はいつでも使えます。

**Lite.8以前はこの機能がないため、最初の1回だけLite.9以降のDMGをダウンロードしてアプリを入れ替えてください。** 古い版へRelease経由で機能を後付けすることはできません。同じタグのファイル差し替えは更新として通知されないため、新しい版番号で公開します。

ダウンロードしたDMGのサイズとGitHubが返すSHA-256を照合し、アプリの署名、識別子、版番号も検証します。更新先に書き込めない場合やDMG上から実行している場合はApplicationsフォルダへの移動を案内します。管理者権限は要求しません。OSのセキュリティ設定も変更しません。入れ替えや開き直しが失敗した場合は旧アプリへ戻します。

更新確認とダウンロードの接続先はGitHubです。認証、Cookie、Macやユーザーの識別情報は送信しません。アプリの版番号はUser-Agentに含めます。前回の確認時刻、応答キャッシュ、スキップした版はローカル設定へ保存します。

## Releaseを公開する側

- タグは `v1.9.4-lite.9` のような3桁の基礎版＋`-lite.N`にします。`.10`は`.9`より新しい版として判定します。
- 下書きは対象外です。番号付きLite実験版はPrereleaseでも通知対象です。通常版やnightly等は混ぜません。
- `SteamAC-Lite-1.9.4-lite.9-macos-arm64.dmg` のようにタグと一致するDMGを添付します。GitHub APIの`digest`が`sha256:`形式で返り、サイズが確定した公開済みの配布物を選びます。
- アプリ内の版番号もタグと一致させます。Releaseの文章だけの変更は更新通知になりません。
- ソースから再現できるよう、署名済みアプリと検証結果・対応する変更済みライブラリのソースを同時に配布します。

## 確認方法

`--selftest-update`は版番号、実験版、ダウンロード元、サイズ、ハッシュ情報、下書き除外を確認します。`scripts/test/in-app-update.py`は破棄できる署名付きアプリで入れ替え、署名破損、版番号不一致、不正なパス、終了待ち、開き直し失敗時の復元を確認します。VMは起動しません。

`--preview-update`はVMを起動せず更新画面だけを表示します。`STEAMAC_UPDATE_URL=file:///.../release.json`と`STEAMAC_FAKE_VERSION=1.9.4-lite.8`で、公開前の通知表示を確認できます。ダウンロード元や配布物の検証は無効にしません。
