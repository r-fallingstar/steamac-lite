起動時の更新通知を改善しました。

- 前回の確認から6時間以内でも、起動するたびに最新版を確認します。新しい版があるときだけ更新画面を表示します。
- 起動中の確認は引き続き6時間ごとです。「あとで通知」「このバージョンをスキップ」と自動確認をオフにする設定も使えます。
- マイク選択、設定画面のサイズ調整、1.9.8への移行内容は引き継いでいます。SteamOSディスク・ゲーム・設定は保持します。

「steamac Lite → アップデートを確認…」から更新できます。BOOTHのネットインストーラーもこの版を取得します。古い版の起動時確認には6時間の間隔が残るため、この版への更新通知が見当たらない場合はメニューから一度確認してください。

Improved startup update notices.

- Every app launch now checks for updates, even if the last check was less than six hours ago. A window appears only when a newer version is available.
- While the app stays open, checks still run every six hours. Later, Skip This Version and the automatic-check opt-out are kept.
- Keeps microphone selection, the resizable settings window and the 1.9.8 migration. SteamOS disks, games and settings are preserved.

Use Check for Updates… or the BOOTH online installer. Older versions retain the six-hour startup limit; use the menu once if this update is not shown automatically.
