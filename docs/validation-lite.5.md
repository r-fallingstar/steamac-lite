# Lite.5の確認範囲

2026-11-02、Apple M1・RAM 8 GiB・macOS 27.2で確認しました。

## 新しいSteamOSディスクでの確認

既存環境のディスクを流用せず、初回画面からValve公式のSteamOSイメージをダウンロードして新しいディスクを作成しました。使用したイメージは `20261022.6150929`、バージョン `0.4.5` です。ログイン情報・ゲーム・互換ツールはコピーしていません。Steamには既存アカウントで本人がログインしました。アカウント自体を新規作成した検証ではありません。

| 項目 | 結果 |
|---|---|
| ディスク作成 | 署名検証、進捗更新、作成完了、Steamの初回ダウンロード、ログイン画面への到達を確認 |
| 準備前の状態 | FEX・Proton Experimental・EACの各manifestなし。完了記録、対応版FEX、VRChatのProton指定と起動オプションもなし |
| Steamからの取得 | FEX-Emu `3127680`、Proton Experimental `1493710`、Proton EasyAntiCheat Runtime `1826330` がすべて `StateFlags=4` |
| Proton | x86_64版 `1793301796 experimental-11.0-20261027b-x86_64` を確認 |
| FEXの追加設定 | 同梱の対応版へ自動で切り替わり、対象10ファイルのSHA-256がすべて一致 |
| VRChat向け設定 | `438100` の互換ツールが `proton_experimental`。EAC用起動オプションと `complete.json` を確認。Steamの自動再起動も完了 |
| 手動で操作した箇所 | 本人によるログイン。検証担当によるSteamのインストール確認と初回ガイド。ガイド終了後の再開にアプリの再起動が一度必要 |
| 元の環境 | 停止後のスナップショットと比較し、ディスク全体の内容が同一であることを確認。インストール済みアプリも置き換えていない |

Protonの指定、FEXの追加設定、起動オプションの編集はアプリの自動処理が行いました。画面操作による設定の代行はしていません。検証用の観測サービスは状態・設定・ハッシュの読み取りだけを行います。SSHは無効のまま、VRChatは起動していません。

Steamの初回ガイド後に次のツールのインストール画面が出ない場合があります。今回の検証ではFEXの取得後に発生し、SteamAC Liteを終了・再起動するとProtonの準備から再開できました。ログインや確認画面も含め、すべて無人で完了するものではありません。

## 初回日本語表示

別の未起動SteamOSディスクで、日本語を選んだランチャーから起動しました。アカウント情報をコピーせず、Steamの初回ログイン画面が日本語であることを実画面で確認しています。

- Steam起動前に `~/.steam/registry.vdf` の表示言語だけを初期化します。
- 既存のSteam設定・言語がある場合や、一度初期化した後は上書きしません。
- 単体テスト7件で、日本語・英語・ロシア語・簡体字中国語の対応、既存設定と手動変更の保持、不正な入力を確認しました。実画面を確認したのは日本語です。

## 初回ディスク作成の修正

Lite.4でディスク作成中の進捗と完了通知が画面へ届かない問題を修正しました。初回モーダル画面をメインキューの長い処理の中から開いていたため、同じキューへ届く通知が待たされていました。メインRunLoopから画面を開くよう変更しています。

本番と同じスケジューラーを使うAppKitの回帰検査に成功し、修正前の処理を使った対照検査では失敗を検出しました。修正後のアプリでは、実際のディスク作成も進捗更新からSteam起動まで完了しました。

## 制限

VRChatのゲーム起動、FPS、長時間の安定性、すべてのMac・SteamOS・Proton更新との互換性は、この新規インストール検証の対象に含みません。以前のユーザーによるVRChat動作報告とは区別しています。

既存の `--selftest-settings` にあるポップアップ内部クラス検出2件の失敗は継続しています。一括UI検査全体が成功したとは扱っていません。今回の初回ディスク作成は専用の回帰検査と実画面で別途確認しました。

配布DMGの署名・整合性・コピー後の自己検査とSHA-256は、Releaseの `distribution-validation.json` と `SHA256SUMS.txt` を参照してください。個人のアカウント情報を含むテスト用ディスクやログは配布しません。
