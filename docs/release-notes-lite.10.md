# steamac Lite 1.9.4-lite.10

アプリの表示名を「steamac Lite」に統一しました。

- メニューバー、終了メニュー、起動時の表示、設定、通知とエラー表示の旧名を修正しました。
- 日本語・英語・韓国語・簡体字中国語・ロシア語で同じ名称を使います。
- ネットインストーラーも1.0.1へ更新しました。

Lite.9からはアプリ内の「アップデートを確認…」で取得できます。初めて使う場合はDMGかネットインストーラーを使ってください。既存のSteamOSディスク、ゲーム、設定は引き継ぎます。更新の互換性を保つため、アプリの保存名・識別子とDMGファイル名は従来の形式を維持しています。

Apple Silicon・macOS 15.5以降向けの実験版です。Appleの公証は受けていません。起動時に応答しなくなる件は引き続き調査中で、今回の変更による改善は未確認です。
