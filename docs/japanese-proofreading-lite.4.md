# Lite.4 日本語表記の校閲

2026-11-02、Antigravityの **Gemini 3.8 Flash High** に、`Localizable.xcstrings` の日本語全項目と、`vrchat-setup` の日本語UIを読み取り専用で校閲してもらいました。変更や公開は依頼せず、指摘を実装と照合して反映しています。

反映した主な内容は、アプリ自身を示す旧製品名の修正、VM再起動の対象の明示、容量不足・メモリ割り当ての説明、画面更新60 Hzの明示、リフレッシュレートの用語統一、音声出力先と送信情報の表記です。「VRChat向け設定」は機能見出し・チェック項目・説明書で統一しました。新しい設定画面のエラーは日本語で原因と次の操作を示します。

校閲案のうち、クラッシュレポートの送信先を「SteamAC Lite開発者」へ書き換える案は採用していません。実際の送信先は上流のFX Steam Launcher開発者のSentryで、Liteでは既定で送信OFFです。表記だけを変えると送信先を誤認させます。

また、順序を変えない書式引数は `%@` のままでも有効で、「位置指定子がないだけで表示が壊れる」という指摘は当てはまりません。日本語の語順を変えた文章には `%1$@` 等を明示し、カタログ検証を行っています。「手動モードの未指定値」と「推奨設定に戻す」は、実際の既定値・リセット動作に合うため保持しています。

修正後のUIと導入手順も同じモデルで再校閲しました。案内文のチェック項目名と再試行の説明を追加で統一しました。一方、実機の `sw_vers -productVersion` は `27.2` のため、「macOS 27.2は存在しないので15.2へ直す」という校閲案は採用していません。

更新確認についても実装を確認し、LiteのメニューからはこのフォークのReleaseページを開くよう変更しました。上流版の更新をLiteの更新と誤認しないよう、Liteでは上流の自動更新確認の項目を表示しません。
