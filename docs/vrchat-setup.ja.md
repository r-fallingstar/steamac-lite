# VRChat向け設定

Lite.4から、初回のディスク選択画面と **設定… > 一般** に **VRChat向け設定** があります。既定で有効です。初回にFEXをビルドしたり、起動オプションを手入力したりする必要はありません。

## 設定の流れ

1. 表示言語を選び、SteamOSディスクを作成・選択します。「VRChat向け設定」を有効にして進めます。
2. Steamに自分のアカウントでログインします。パスワードやSteam Guardの確認は本人が操作します。
3. FEX-Emu、Proton Experimental、Proton EasyAntiCheat Runtimeの準備を順に進めます。未インストールの場合はSteamのインストール画面を開きます。確認画面が表示されたら、内容を確認してインストールしてください。利用条件の確認も本人が行います。
4. ダウンロードが完了すると、追加設定を自動で適用します。ゲームの実行中は終了を待ち、Steamを一度終了して設定後に起動します。
5. 「VRChat向け設定が完了しました」と表示されたら完了です。VRChatが未インストールの場合はSteamでインストールし、準備ができたら起動します。

**VRChatは自動では起動しません。** Steamへのログイン、Steamに表示される確認、ゲームのインストールと起動は本人が操作します。ツールの取得はSteamが行うため、接続状況やSteam側の対応状況によって待機することがあります。

## 自動で設定する内容

| 項目 | 内容 |
|---|---|
| FEX | ValveのFEX-Emuツールを用意したうえで、同梱の対応版 `eac-2610.5` を導入。コミットとファイルのSHA-256を固定し、導入前に検証 |
| Proton | **VRChatだけ**を `proton_experimental` に設定。x86_64版を確認してから完了と判定 |
| EACランタイム | Steamから **Proton EasyAntiCheat Runtime** を取得し、その保存先を起動オプションに設定 |
| 起動オプション | `EAC_LAUNCHERDIR`、`PROTON_EAC_RUNTIME`、`WINEDEBUG=-all`、`PROTON_USE_XALIA=0`、`WINE_CPU_TOPOLOGY` を設定。CPU番号はVMのCPU数に合わせる |

FEX-EmuはSteamが互換ツールとして管理するため、土台となるValve版も必要です。対応版のFEXはアプリに同梱しており、利用者のMacでのコンパイルやSSHの有効化は不要です。Proton・EACランタイム・VRChat本体・ログイン情報は配布アプリに含みません。

## 中断・既存設定・バックアップ

「あとで設定する」で画面を閉じられます。完了していなければ次回のSteam起動時に続けます。インストール画面をキャンセルした場合は「再試行」でもう一度開けます。ダウンロード途中のファイルは導入済みとして扱いません。

独自の互換ツールや起動オプションがある場合は自動では置き換えません。置き換える場合は画面の「既存のVRChat向け設定を置き換える」にチェックを入れて「再試行」を押します。既存の対応済み起動オプションは、追加の引数も含めて保持します。他のゲームやSteam全体の互換ツール指定は変更しません。

SteamOS内の `~/.config/steamac/vrchat-setup/` に状態と原本を保存します。

- `valve-fex-backup/`：置き換える前のFEXの10ファイル。
- `config-backups/<アカウントID>/`：初回変更前の `config.vdf` と `localconfig.vdf`。
- `complete.json`：設定の完了記録。パスワードは保存しません。

バックアップの設定ファイルにはアカウント固有の情報があるため、公開しないでください。設定を戻す場合は原本のVRChatの項目を参照してSteamで変更してください。Steam全体のファイルを丸ごと戻すと、設定後の変更も戻るため注意してください。

SteamがFEX-Emuを更新した場合は、次回のSteam起動前に対応版を再適用します。更新直後に動かなくなった場合は、ゲームを終了してSteamAC Liteを再起動してください。「VRChat向け設定」を無効にすると、以後の自動処理を停止します。すでに適用したSteamの設定は保持されます。

## 確認範囲

M1・RAM 8 GBの停止済みテスト用ディスクで、Valve版FEXからの導入、ハッシュ検証、バックアップ、VRChatだけへのProton指定、起動オプションの追加、Steam再起動と正常終了を確認しています。テストではVRChatを起動していません。ツールがすでに入ったディスクを使っており、新規アカウントでの全ダウンロード完了や、すべてのSteamOS・Proton更新との互換性は未確認です。
