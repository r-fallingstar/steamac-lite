steamac LiteをDMGから開くと、アプリケーションフォルダへのインストールを案内するようになりました。

- 「インストールして開く」でアプリをコピーし、コピー先を起動します。表示言語の選択とSteamOSの準備は、その後に進みます。
- 同じ版や新しい版がすでにあれば、そのアプリを開きます。旧版が起動中の場合は、終了してからの更新を案内します。
- アプリの署名をコピー前後に検証します。通常のApplicationsに書き込めない場合は、ユーザー用のApplicationsを使います。
- SteamOSディスクと設定は保持します。日本語・英語・韓国語・簡体字中国語・ロシア語で案内します。
- 導入ガイドの手順を4言語で更新しました。

本機能はアプリの起動後に動作します。macOSによる起動前の確認が表示された場合は、入手元を確認して画面の案内に従ってください。

既存ユーザーは「アップデートを確認…」から更新できます。BOOTHのネットインストーラーも最新版の本体を取得します。配布ファイル名とアプリの保存名は、更新機能との互換性のため従来どおりです。

Opening steamac Lite from a DMG now offers to install the app into Applications.

Choose **Install and Open** to copy and launch the installed app before language selection or SteamOS setup. Existing SteamOS disks and settings are kept. A matching or newer installed version is opened without a downgrade; an older app that is running must be closed before replacement. The app verifies signatures before and after copying and uses the user's Applications folder if the system folder is not writable.

The prompt supports all five app languages. The setup guide has been updated in Japanese, English, Korean and Simplified Chinese. macOS may still require approval before the app can run.
