# Lite.4の確認範囲

2026-11-02、Apple M1・RAM 8 GiB・macOS 27.2で確認しました。

| 項目 | 結果 |
|---|---|
| VRChat向け設定の単体テスト | 13件成功。初回ログイン待ち、ARM Steamのアカウント検出、既存設定の保持、Steam全体・他ゲームの指定の保持、破損・未完了ダウンロード・ARM版Protonの拒否、書き込み失敗時の復元、FEX更新後の再適用 |
| 同梱FEX | 固定コミット、アーカイブSHA-256、導入対象10ファイルとライセンスの検証に成功 |
| SteamOS初回処理 | 停止済みテスト用ディスクでValve版FEXへ戻し、VRChatの互換指定と起動オプションを外してから起動。実際のuser serviceで自動設定とSteam再起動に成功。10ファイルのハッシュ、原本保存、Proton指定、起動オプションを確認。約27秒でVMの正常終了まで完了 |
| FEX更新後の復旧 | 完了記録を保持したままテスト用ディスクのFEXをValve版へ戻し、次回Steam起動前に同梱版へ戻ることを確認。約26秒でVMの正常終了まで完了 |
| 初回画面 | 独立した設定領域の検証用アプリで、日本語の「VRChat向け設定」、既定ON、ON/OFF操作、説明文をAccessibilityで確認。SteamOSディスクの作成・ログイン・利用条件の承諾は行っていない |
| 一般設定 | 日本語の項目・説明文・次回起動の案内を描画画像で確認 |
| 日本語表記 | Gemini 3.8 Flash Highで全日本語UIを校閲し、修正後のUI・導入手順を再校閲。実装・実機情報と照合して反映 |
| 既存機能の回帰検査 | キーボード設定8件、スワップ7件、FEX手動インストーラー6件成功。ランチャーの性能プロファイル・配列・言語の自己検査と多言語カタログ検査も成功 |

テストではSSHを有効にせず、VRChatを起動していません。ツールが導入済みのディスクを使っているため、ツール未導入の新規アカウントでSteamから全ダウンロードが完了する過程は未確認です。Steamの確認画面は本人による操作が必要です。

既存の `--selftest-settings` は、Lite.3と同じポップアップ内部クラスの検出2件が失敗します。全タブの画像出力とその他の検査は実行しましたが、一括UIテスト全体の成功とは扱っていません。初回項目の表示・選択は別途実画面のAccessibilityで確認しています。NSAlertのオフスクリーン画像は一部の描画が欠けるため、初回画面の見た目を画像だけで検証したとは扱っていません。

配布DMGの署名・マウント・コピー後の自己検査とハッシュは、Releaseの `distribution-validation.json` と `SHA256SUMS.txt` に保存します。実ゲーム性能やすべてのMac・将来のSteam/Proton更新との互換性は保証していません。
