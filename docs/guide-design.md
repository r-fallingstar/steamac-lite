# 導入ガイドのデザイン

明るく親しみやすい、日本の文具・キャンディステッカー調のかわいいポップデザインを採用しています。

- 背景はサクラミルク（`#FFF6FB`）に淡いパステルの水玉模様を散りばめ、ページ最上部にはスカラップ調のパステルリボンを添えています。カードは均一な 2.5px 枠線と立体的な底面シャドウで構成し、カード横・上端の太いアクセント線、ぼかし背景、すりガラス調、グラデーション文字は使っていません。
- 配色はストロベリーピンク（`#FFEAF5`）・ラベンダー（`#F3EAFF`）・クリームソーダブルー（`#E5F8FF`）・ハニーレモン（`#FFF5CC`）の 4 色で整理し、主要ボタンはつや感のある単色キャンディベリー（`#D42C7C`）にしています。
- ヒーローには手描き風の雲・お星さま・ハートの飾りと白ふちステッカー風タイトル、ポラロイドや補足メモカードにはストライプ柄のマスキングテープ風飾り、目次カード上部にはリングノート風の穴飾りをあしらっています。
- ヘッダー右上の切り替えボタンで、明るいポップ調（標準）と落ち着いたゆめかわナイトのダークモードを切り替えられます。
- 見出しには丸みのある `Fredoka` と `Zen Maru Gothic`、ファイル名や `<kbd>` キー表記には `JetBrains Mono` を用い、英語・韓国語・簡体字中国語向けのフォント設定を維持しています。
- ボタンや本文・注釈の配色は 4.5:1 以上のコントラスト比を確保しています。4 言語の文章、設定写真、リンク、画像拡大機能、JavaScript・ストレージ無効時の言語ルーティングやアプリ本体の動作は従来のまま維持しています。
