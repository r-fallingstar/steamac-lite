# 導入ガイドのデザイン

利用者の指定に従い、[kisaragirion.com](https://kisaragirion.com/)の配色と形状を参考にしています。

- 背景は白と淡いピンク。写真の背面と補足欄にはラベンダーを使用。
- 本文は紫がかった濃色。ダウンロードボタンは白文字とのコントラストを確保した濃いピンク。
- 写真は白枠、手順は角丸のカード、見出しはピンクと紫に統一。
- 設定写真・文章・手順・リンク・画像拡大機能は維持。参考サイトの画像やフォントファイルは転用していない。

配色の参考値：ピンク `#ee5ba8`、ラベンダー `#a17bdf`、本文 `#493050`、背景 `#fffcff`。小さい文字やボタンには濃色を使用しています。

画像と本文の見え方をPC・スマホ幅で確認し、ボタンと本文の主要な組み合わせは4.5:1以上のコントラスト、大きな見出しは3:1以上としています。配布アプリ自体の画面や動作は変更していません。
