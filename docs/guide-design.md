# 導入ガイドのデザイン

ポートフォリオサイト（`r-fallingstar.github.io`）の Pop Designer Gothic トーンに合わせ、ラベンダー × サクラピンク基調のモダンなガラスカード・システムとライト／ダーク（Dawn / Nocturne）切り替えに対応しています。

- 背景は淡いオーロラグラデーションとドットグリッド（ライト `#FCF9FF`／ダーク `#100B1C`）で構成し、手順カードや目次・FAQは透過ガラスカードと立体オフセットシャドウで整理しています。
- タイトルと見出しには `Outfit` と `Zen Kaku Gothic New`、ファイル名やショートカットキーの `<kbd>` には `JetBrains Mono` を組み合わせています。英語・韓国語・簡体字中国語の各ページでは言語ごとのフォント設定を維持しています。
- ヘッダーはスクロールに追従するピル型のガラスナビゲーションとし、ライト／ダーク切り替えボタンと言語セレクターを右上に配置しています。
- 主要ボタンはコントラスト比 4.5:1 以上を確保した紫〜濃ピンクのグラデーション、本文・注釈・警告欄もライト／ダーク双方で可読性を保つ配色としています。
- 4言語の文章、設定写真、各種リンク、画像拡大モーダル、JavaScript・ストレージ無効時の言語ルーティングやアプリ本体の動作は従来のまま維持しています。
