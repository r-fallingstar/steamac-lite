# 導入ガイドのデザイン

明るく親しみやすい日本のポップ＆かわいいマカロン調のデザインシステムを採用しています。

- 背景は温かみのあるサクラミルク（`#FFF8FC`）で、カードははっきりした白地と均一な 2px 枠線、立体的なパステル底面シャドウ（レッジ）で構成しています。カードの左側や上端の太い飾り線、ぼかした背景、グラデーション文字、すりガラス調の表現は使っていません。
- 配色はストロベリーピンク（`#FFEAF4`）・ラベンダー（`#F3ECFF`）・ソーダブルー（`#E9F5FF`）・レモンクリーム（`#FFF6D6`）のマカロン 4 色で整理し、主要ボタンは押し込み感のある単色ベリーピンク（`#CC2978`）としています。
- ヘッダー右上の切り替えボタンで、明るいポップ調（標準）と落ち着いたミッドナイトベリーのダークモードを切り替えられます。
- 見出しには丸みのある `Fredoka` と `Zen Maru Gothic`、ファイル名や `<kbd>` キー表記には `JetBrains Mono` を用い、英語・韓国語・簡体字中国語向けのフォント設定を維持しています。
- ボタンや本文・注釈の配色は 4.5:1 以上のコントラスト比を確保しています。4 言語の文章、設定写真、リンク、画像拡大機能、JavaScript・ストレージ無効時の言語ルーティングやアプリ本体の動作は従来のまま維持しています。
