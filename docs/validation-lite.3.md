# Lite.3の確認範囲

2026-11-02、Apple M1・RAM 8 GiB・macOS 27.2で確認しました。

| 項目 | 結果 |
|---|---|
| 容量別の自動設定 | 8・12・16・18・24・32・36・48・64・128 GiBの模擬ホストで成功 |
| 優先順位と保存 | CLI・保存済み手動値の優先、再読込、自動設定への復帰で成功 |
| 画面サイズ | 小さい画面への縮小、8 GBに大きな画面をつないでも自動値を引き上げない検証に成功 |
| 日本語カタログ | ru・zh-Hans・jaの661項目の実行時検証に成功。コンパイラーで抽出した文字列の網羅・置換引数も検査 |
| 初回言語選択 | 実画面で日本語・English・Русский・简体中文を確認。日本語を選び、プロセス再起動後に日本語セットアップ画面を確認 |
| 言語の保存 | 検証用アプリを終了・再起動し、言語選択を繰り返さず日本語の初期設定へ進むことを確認 |
| 設定画面 | 各タブを描画し、日本語の一般・画面設定を画像で確認。項目名・説明文・ボタン・数値を確認 |
| 日本語入力 | IBusの専用コンテキストで「nihongo→日本語」、かな・英数・Control＋Spaceの検証に成功 |
| 配列と更新頻度 | 両XwaylandのJIS記号キー・XIM登録、59.96 Hzの表示を確認 |
| Pythonテスト | 入力設定8件、スワップ7件に成功 |

既存の`--selftest-settings`は全タブの画像出力、メモリ・時刻・音声等の検査を実行しましたが、この環境ではNSButtonの内部クラスを探すポップアップ検出2件が失敗します。表示上はゲームの描画・ドライバー・評価の各PickerとウインドウサイズのPickerが存在します。この一括UIテスト全体の成功とは扱っていません。初回の言語選択・再起動・日本語表示は、上記の別の実画面確認で検証しています。

大容量Macの実ゲーム性能、すべてのMac・macOS、VRChat内の日本語入力・長時間動作はこのテストでは確認していません。配布DMGの検証結果とハッシュはReleaseの`distribution-validation.json`と`SHA256SUMS.txt`に保存します。
